# ABR & ARN - Demo interactive

Application web (Python, sans dependances externes) pour comprendre les operations sur les
Arbres Binaires de Recherche (ABR) et les Arbres Rouge-Noir (ARN) : parcours (largeur,
prefixe, infixe, postfixe), insertion, suppression, minimum, maximum, successeur,
predecesseur, rotations, avec trace detaillee pas a pas.

## Lancer en local

```bash
python main.py
# puis ouvrir http://localhost:8000
```

## Deploiement gratuit

Compatible Render / Railway / Fly.io. Le port est lu depuis la variable d'environnement `PORT`.
Start command : `python main.py`.

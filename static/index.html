    Principes des opérations

    Parcours en largeur (BFS)

    Visite niveau par niveau de gauche à droite à l'aide d'une file (FIFO). Utile pour le chemin le plus court.

    Parcours préfixe / infixe / postfixe

    Préfixe : nœud, gauche, droite. Infixe : gauche, nœud, droite (donne les clés triées pour un ABR). Postfixe : gauche, droite, nœud.

    Insertion (ABR)

    Descente depuis la racine en comparant la clé, puis attachement du nouveau nœud comme feuille à gauche ou à droite.

    Suppression (ABR)

    Feuille : détachement. Un enfant : remplacement par l'enfant. Deux enfants : remplacement par le successeur (minimum du sous-arbre droit), puis suppression du successeur.

    Successeur / Prédécesseur

    Successeur : minimum du sous-arbre droit, sinon premier ancêtre pour lequel le nœud est dans le sous-arbre gauche. Prédécesseur : symétrique.

    Rotations

    Réorganisation locale conservant la propriété ABR, utilisée pour rééquilibrer (AVL, rouge-noir). Rotation gauche/droite en O(1).

    Arbre rouge-noir : propriétés

    1) Nœud rouge ou noir. 2) Racine noire. 3) Feuilles (NIL) noires. 4) Un nœud rouge a des enfants noirs. 5) Tous les chemins ont le même nombre de nœuds noirs.

    Insertion (ARN)

    Insertion comme ABR, nœud coloré en rouge, puis correction : cas oncle rouge (recoloration) ou oncle noir (rotation + recoloration).

    Suppression (ARN)

    Suppression comme ABR ; si un nœud noir est retiré, correction du déficit de noir via les cas du frère (rouge, noir à enfants noirs, enfant rouge).
